Head Aim + Snap/Smooth/Physical turn in RE9

Features:
- Can turn either by Physical turn or Snap/Smooth turn.
- Head Aim for aiming.
- Use a gamepad for controls

Installation:

- Remove any other scripts RE9 scripts beforehand as they might conflict with this mod.
- Install the latest version of Praydog's Reframework VR mod or PureDark's AFW version: https://github.com/PureDark/REFramework/releases
- Place re9_vr_hmd_aim_movement.lua under reframework\autorun under your RE9 game dir.
- Adjust settings in "HMD Aim and Enhanced Movement" under Script Generated UI. Smooth turning speed is adjustable under Script Generated UI not game's settings.
In game settings:

Disable Aim Assist
- Set First-person camera for both characters
- Set Camera Wobble to 0
- Take off scopes before aiming
